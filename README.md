# raw-prompt-to-pro

Agent skill: turn a raw one-line image prompt into a professional, paste-ready prompt for ChatGPT, Gemini, Grok, OpenClaw, Hermes, Codex, OhMyPi, Flux, Midjourney.

## Install

Copy this folder into your agent's skills directory so `SKILL.md` sits at:

`skills/raw-prompt-to-pro/SKILL.md`

Keep `references/` next to it.

## Use

Give the agent a rough line such as:

> Tạo hình cô gái Việt Nam xinh, sexy, cổ V-neck

It returns Intent lock, Flat prompt (English), Negative, and short platform wrappers. It does not generate an image unless you ask.
